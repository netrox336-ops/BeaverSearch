# BeaverSearch — Third Party Notices

## yooma.su

BeaverSearch читает публичные страницы серверов/профилей yooma.su для live monitoring и извлечения Steam identity из публичной разметки/состояния. BeaverSearch не является продуктом yooma.su и не аффилирован с владельцем сервиса. Структура страниц, доступность и rate limits контролируются владельцем сайта.

## CYBERSHOKE

BeaverSearch читает публичные CS2 monitoring pages CYBERSHOKE и использует только публично отображаемые/передаваемые player identity fields. BeaverSearch не является продуктом CYBERSHOKE и не аффилирован с CYBERSHOKE ESPORTS LIMITED. Изменение DOM/API/state может потребовать обновления parser.

## Microsoft Edge / Google Chrome

Для страниц, чей live roster создаётся JavaScript, BeaverSearch может запускать уже установленный Edge или Chrome в headless режиме через Chrome DevTools Protocol (CDP). Браузеры не включены и не перераспространяются с BeaverSearch. Используется временный отдельный профиль без доступа к пользовательским cookies/login profile.

## Steam / Valve

Steam, Counter-Strike 2 и Dota 2 относятся к Valve Corporation. BeaverSearch обращается к публичным Steam Community profile/inventory endpoints и не является продуктом Valve/Steam.

## Skinport / CSFloat / CBR

Skinport и CSFloat используются как внешние источники рыночных данных; CBR — как источник валютных данных при необходимости. BeaverSearch не аффилирован с этими сервисами.

## Rust

Rust относится к Facepunch Studios. Название/иконка используются только для обозначения Steam inventory category.

## Lucide Icons

Часть vector line-icon geometry интерфейса основана на Lucide Icons (ISC; upstream Feather/MIT). Runtime package Lucide не включается.

## .NET / WPF

BeaverSearch построен на Microsoft .NET 8 и Windows Presentation Foundation (WPF). Self-contained publish может включать применимые Microsoft runtime components на условиях соответствующих лицензий.
